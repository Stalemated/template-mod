# Template Mod

Template Mod description.

## Dependencies

- Fabric only: [Fabric API](https://modrinth.com/mod/fabric-api)
- [S-Lib](https://modrinth.com/mod/s-lib)
- **Optional:** [YACL](https://modrinth.com/mod/yacl) for the in-game config screen
- **Optional, Fabric only:** [Mod Menu](https://modrinth.com/mod/modmenu) for the config button
